# Blackjack Game ♠️

A simple browser-based Blackjack game built with HTML, CSS, and JavaScript. Practice the basics of card games while exploring JavaScript logic and DOM manipulation.

## ✨ Features
- Interactive card drawing
- Dynamic score calculation
- Game status updates
- Start and new card functionality

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (DOM Manipulation, Functions, Arrays, Event Handling, and Conditional Logic)

## 🚀 Getting Started
Clone the repository and open `index.html` in your browser.

```bash
git clone - https://github.com/Anika-Aktar/Blackjack-Game.git
```
